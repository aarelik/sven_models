# Quick Revive - Half-Life inspired static model

Blue and cream Quick Revive machine inspired by the supplied reference, with a sloped top, raised nameboard, round rescue sign and bottle hatch. Static prop; no perk scripts or gameplay included.

Copy svencoop_addon into your Sven Co-op game folder. In J.A.C.K., use a cycler with model `models/zombies/quickrevive_hl1.mdl`. Place the origin on the floor. Front faces negative Y. Normal rendering, skin 0, idle sequence 0. Include that model path in your map resource list.

346 triangles, 241 welded vertices, one bone and one static idle sequence. Dimensions: 43 x 30.5 x 97.2 GoldSrc units. Textures are embedded in the MDL. Compiled with the installed Sven Co-op SDK and structurally validated; not tested in game.

Includes MDL, GLB, OBJ/MTL, SMD/QC and indexed textures. Run studiomdl.exe quickrevive.qc from source to recompile. GLB is Y-up metres; OBJ/SMD use Z-up GoldSrc units. Front artwork generated with the built-in image tool; mesh and other texture sheets authored for this model. Unofficial fan-made interpretation.
