# Mystery Box - Half-Life inspired static model

Closed wooden chest with painted question marks, iron straps, hinges, latch and carrying handles. Static model only; no scripts, gameplay or opening animation.

Copy svencoop_addon into your Sven Co-op game folder. In J.A.C.K., use a cycler with model `models/zombies/mysterybox_hl1.mdl`. Place the origin on the floor. Front faces negative Y. Normal rendering, skin 0, idle sequence 0. Include that model path in your map resource list.

336 triangles, 224 welded vertices, one bone and one static idle sequence. Dimensions: 81 x 33.95 x 30.6 GoldSrc units. Textures are embedded in the MDL. Compiled with the installed Sven Co-op SDK and structurally validated; not tested in game.

Includes MDL, GLB, OBJ/MTL, SMD/QC and indexed textures. Run studiomdl.exe mysterybox.qc from source to recompile. GLB is Y-up metres; OBJ/SMD use Z-up GoldSrc units. Lid artwork generated with the built-in image tool; mesh and other texture sheets authored for this model. Unofficial fan-made interpretation.
