# Sven Models

Low-poly Half-Life inspired props for Sven Co-op.

- [Juggernog interactive viewer](https://aarelik.github.io/sven_models/)
- [Double Tap interactive viewer](https://aarelik.github.io/sven_models/doubletap.html)
- [Double Tap complete model pack](https://aarelik.github.io/sven_models/doubletap-hl1-model-pack.zip)
- [Double Tap installation and source notes](models/doubletap/README.md)

Double Tap includes a compiled MDL, GLB, editable OBJ/SMD/QC source, indexed textures and previews. Its SDK compilation and structural checks passed; in-game testing is pending. The Juggernog model was tested in game by the repository owner.

Future models are added here with their own viewer and downloads.
